# Contribuição

1. Mantenha os testes independentes e use esperas explícitas em vez de `Thread.sleep`.
2. Preserve dados pessoais reais fora dos testes; use dados fictícios e e-mails reservados.
3. Execute `mvn clean test` antes de abrir uma contribuição.
4. Não adicione `target/`, credenciais, senhas pessoais ou configurações locais ao repositório.
